# App icon

`icon.svg` is original geometric campus artwork created for this independent student app. It is not the Myongji seal, an official logo, or a depiction of a specific campus building. `icon.png` is the 1024 × 1024 opaque store/app icon. `adaptive-foreground.png` is a transparent, inset rendering for Android adaptive-icon masks; its background is set in Expo configuration.

The publisher can use or replace these assets under the project's license. Preview the installed icon on physical devices and approve final store branding before release.
