# Myongji Campus Explorer — project showcase

**A campus guide for Yongin and Seoul in English, Korean and Simplified Chinese, bringing building discovery, food, transport and practical questions into one mobile interface.** This independent project can be demonstrated in an international-operations internship conversation without implying university affiliation or a deployed university service.

## The student problem

A newcomer may know a classroom code but not the building, need a coffee between classes, or struggle to reconcile a student guide with an official bus timetable. Campus information is spread across Korean university pages, visual maps and informal guidance. The project makes that information easier to explore while preserving the evidence and uncertainty behind it.

## A two-minute demonstration

1. Select **Yongin**, search **Y3** or **명진당**, select the building, switch between 3D and 2D and zoom into the campus. Explain that real names and official markers anchor the illustration, while building shapes remain approximate.
   Open **Illustrated map · sources** to show the reference catalogue and distinguish reviewed photographs from remaining evidence gaps. Toggle **Aa** to demonstrate uncluttered exploration.
2. Open **Food**, select coffee and show a venue's source and building action. Point out that missing hours and prices are left unverified.
3. Open **Buses**, choose a direction and show its origin, published departure table and Seoul-time highlighting. Explain the distinction between a schedule and a live arrival.
4. Ask **Where is classroom Y9228?** Show the source-backed building response and map action. Then ask about an unsupported personal class assignment to demonstrate a clear unknown answer.
5. Switch to **Seoul** to show its separate places, food listings and transport notices. Change the interface language to demonstrate the three available languages.

## Scope and next release gates

Version 0.5 contains 50 Yongin map references and 11 Seoul references, 14 Yongin food/store listings and four Seoul food facilities, five Yongin published timetable options, and a deterministic offline assistant. Seoul transport is presented through notices and directions, with no active departure timetable saved. Events remain empty until reviewed information is supplied. The primary Android app uses Java/System WebView; the PWA and separate Expo Android/iPhone source are also included. The latest [test report](TEST_REPORT.md) and [native record](NATIVE_VALIDATION.md) state what was actually validated.

Before a store release, the project needs final publisher details and signing, public privacy/support pages, Android and iPhone device acceptance, accessibility and performance checks, current content review, and store submission. Publishing source code does not complete those release gates. Accurate walking navigation would additionally require surveyed entrances and pedestrian paths. A literal measured 3D reconstruction requires authoritative building footprints and heights.
